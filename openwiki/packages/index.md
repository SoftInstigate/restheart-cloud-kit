# Files

- [@restheart-cloud/kit-ng](kit-ng.md) - Angular adapter for RESTHeart Cloud Kit. Provides RhAuthService with signals, route guards, and HTTP interceptor for Angular applications.
- [@restheart-cloud/kit-react](kit-react.md) - React adapter for RESTHeart Cloud Kit. Provides context, hooks, and route guards, plus a /next subpath for Next.js SSR support.
- [@restheart-cloud/kit-vue](kit-vue.md) - Vue adapter for RESTHeart Cloud Kit. Provides composables and navigation guards, plus a /nuxt subpath for Nuxt SSR support.
- [@restheart-cloud/kit](kit.md) - Core authentication package with zero dependencies. Provides all auth flows, token management, team operations, consents gating, and password reset functionality.
