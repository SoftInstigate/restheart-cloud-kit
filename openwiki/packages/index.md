# Files

- [@restheart-cloud/cli](cli.md) - CLI tool and library for idempotent, file-driven configuration of RESTHeart Cloud services. Provides the rhc command, admin and service clients, session management, environment variable secret resolution, and a step-based setup runner.
- [@restheart-cloud/kit-ng](kit-ng.md) - Angular adapter for RESTHeart Cloud Kit. Provides RhAuthService with signals, route guards, HTTP interceptor, payments service, and cart service for Angular applications.
- [@restheart-cloud/kit-react](kit-react.md) - React adapter for RESTHeart Cloud Kit. Provides context, hooks, and route guards for authentication, payments, and cart, plus a /next subpath for Next.js SSR support.
- [@restheart-cloud/kit-vue](kit-vue.md) - Vue adapter for RESTHeart Cloud Kit. Provides composables and navigation guards for auth, payments, and cart, plus a /nuxt subpath for Nuxt SSR support.
- [@restheart-cloud/kit](kit.md) - Core framework-agnostic package with zero dependencies. Provides authentication, token management, team operations, consents gating, password reset, payments, orders, cart, and money formatting.
